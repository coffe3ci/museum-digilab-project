# museum-digilab-project


**main.py**

Start de applicatie en verbindt de schermen met elkaar. ``` python main.py ```

**home_screen.py**

Het hoofdscherm waarop de objecten worden weergegeven.

**home_screen.kv**

Het ontwerp van het hoofdscherm, zoals de kleuren en tekstgroottes.

**object_screen.py**

Toont de informatie van het geselecteerde object.

**object_screen.kv**

Het ontwerp van het objectdetailscherm.

**admin_screen.py**

Het inlog- en beheerscherm voor de beheerder.

**admin_screen.kv**

De vormgeving van de beheerschermen.

**object_manager.py**

Beheert het toevoegen, verwijderen en bewerken van objecten.

**admin_manager.py**

Controleert de gebruikersnaam en het wachtwoord van de beheerder.

**database.py**

Beheert de SQLite-database.

**assets/objects/**

Bevat de afbeeldingen van de museumobjecten.
